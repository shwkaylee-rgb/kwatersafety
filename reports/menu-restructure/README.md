## 생존수영 인증서 등록(보호자)
- 대표님 결정대로 **첫 화면 히어로 안 카드**와 **주요사업 메뉴**에만 둠(상단 오른쪽 파란 바로가기·푸터 별도 링크는 뺌). 푸터 사이트맵은 메뉴를 그대로 보여 주는 것이라 주요사업 아래에 함께 나옴.
- 첫 화면 카드: 바다 배경 그대로, 소개 문구 바로 아래 흰 카드 "학부모님께 / 생존수영 인증서 등록(보호자)" + [인증서 등록하기 →] + "이미 등록했어요 · 이수증 보기"(mypage.html#swim). 휴대폰 390×844에서도 스크롤 없이 보임.
- swim.html(g 없이): 5단계 안내(학교 QR·링크 → 로그인/가입 → 자녀 정보 → 법정대리인 동의 → 마이페이지 이수증), "받은 링크 붙여넣기" 칸(링크 끝 g 값을 꺼내 swim.html?g=…로 이동, 화면 안에서만 처리), 기존 학교 이름 찾기 유지, 마이페이지 이수증 보기·문의 전화. g가 있을 때 흐름·Firestore 규칙은 그대로.

## 추가 결정 반영
1. **수상인명구조사 삭제**: 메뉴·sitemap·SEO 표·인재육성 본문 카드/문장에서 제거(인재육성 소개문은 "착의생존수영지도자·영유아수상교육전문지도자 자격 과정과 응급처치 이수교육"으로). `cert-lifeguard.html`은 noindex 안내 페이지("더 이상 운영하지 않습니다")로 바꾸고 4초 뒤 `cert-instructor.html`로 이동. 옛 아임웹 주소 `45/index.html`도 바로 `cert-instructor.html`로 가게 고침. 남은 언급은 이 안내 문장 하나뿐. "구조 인력"(현장 인력 일반) 표현은 자격 소개가 아니라 그대로 둠.
2. **영유아수상교육전문지도자** `cert-infant.html` 새로 만듦(착의생존수영지도자와 같은 틀). 쓴 사실: 협회 자격, 1급·2급, 유효기간 2년(갱신교육 이수 시 연장, qual-config.js), 자격번호 KWSA-IW-연도-일련번호, 자격 확인 조회. **비워 둔 칸(확정 자료 필요)**: 자격 소개 상세 설명, 무엇을 익히나요(교육 내용), 등급별 직무 내용, 등급별 검정 기준, 응시 자격·교육 시간, 민간자격 등록번호(qual-config.js regNo 빈 값). → "세부 기준은 공지사항·교육일정에서 안내" 상자로 대신. 참고: qual-config.js 이름은 띄어쓴 "영유아 수상교육전문지도자"라 표기 통일 여부 확인 필요.
3. **자료실** `resources.html`(알림마당 하위, sitemap 추가): 기존 회원 자료실(마이페이지 > 회원 자료실, library.js·getResourceFile)과 겹치지 않게 공개 안내 페이지로만 만듦. 내용: "가이드북 1호 발간 준비 중(2027년 2월 예정)" + 회원 자료실 바로가기(mypage.html#library)·회원 안내.
4. **'플러미' → '누워뜨기 연습기구'**: 생존수영 공공교육 페이지 4곳(제목·본문·사진 자리·사진 설명). 운영사 이름: 아쿠아넥스 없음, **에쓰엔피씨·한국수난학회** 각 1회가 생존수영 공공교육 페이지 "특수아동 맞춤형 생존수영 프로그램" 문장("주요 협력사인 에쓰엔피씨와 한국수난학회에 제안")에 남아 있음(지시대로 고치지 않음). reports/design-refresh/README.md(옛 보고서)에도 같은 단어가 있음.
