## 스크린샷 (1280폭 `-desktop`, 390폭 `-mobile`)
- `home-*`: 첫 화면(히어로 안 「생존수영 인증서 등록(보호자)」 카드, 상단 오른쪽 바로가기)
- `menu-dropdown-1~5-desktop`: 대메뉴별 드롭다운 / `menu-open-mobile`: 휴대폰 메뉴
- `swim-no-link-*`: swim.html을 링크 없이 열었을 때 보호자 안내 화면(전체 길이)
- `tabs-about-*`, `tabs-activities-*`, `tabs-education-*`: 하위 탭
- `footer-*`: 푸터 사이트맵·바로가기 / `verify-*`: 메뉴에서 뺀 자격 확인 페이지(배너 유지 확인)
