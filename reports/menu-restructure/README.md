- 브랜치: `menu/restructure` (main에는 아직 반영하지 않음)
- 비교: https://github.com/shwkaylee-rgb/kwatersafety/compare/main...menu/restructure
- 메뉴 원본: `assets/js/common.js`의 `MENU`(대메뉴·하위 메뉴)와 `QUICK`(상단 오른쪽 바로가기)

## 스크린샷 (1280폭 `-desktop`, 390폭 `-mobile`)
- `home-*`: 첫 화면(히어로 안 「생존수영 인증서 등록(보호자)」 카드, 상단 오른쪽 바로가기)
- `menu-dropdown-1~5-desktop`: 대메뉴별 드롭다운 / `menu-open-mobile`: 휴대폰 메뉴
- `swim-no-link-*`: swim.html을 링크 없이 열었을 때 보호자 안내 화면(전체 길이)
- `tabs-about-*`, `tabs-activities-*`, `tabs-education-*`: 하위 탭
- `footer-*`: 푸터 사이트맵·바로가기 / `verify-*`: 메뉴에서 뺀 자격 확인 페이지(배너 유지 확인)

- 자격 확인: 메뉴에서 빼고 상단 오른쪽 작은 링크, 교육과정 자격 3페이지 하단 버튼(교육 신청·교육일정 옆), 푸터 링크. 메뉴 밖 페이지가 되어 `data-page-title="자격 확인"`으로 배너 유지.
- 멤버십 신청: 로그인 전에는 기존 `requireLogin()`이 `login.html?back=membership-apply.html`로 보내고, 로그인 후 돌아옴(확인함).
- 파일명·SEO 표·sitemap 항목은 그대로(sitemap은 빌드 날짜만 갱신).

## 첫 화면 인증서 등록
- 히어로(바다 배경 그대로) 소개 문구 바로 아래 흰 카드: "학부모님께 / 생존수영 인증서 등록(보호자)" + [인증서 등록하기 →](swim.html) + "이미 등록했어요 · 이수증 보기"(mypage.html#swim). 휴대폰 390×844에서도 스크롤 없이 보임.
- 상단 오른쪽 파란 알약 링크 "인증서 등록(보호자)" (휴대폰 메뉴 맨 위에도), 푸터에도 링크.

## swim.html(g 없이) 안내 화면
1~5단계 카드(학교에서 받은 QR·링크 열기 → 로그인/회원가입 → 자녀 정보 → 법정대리인 동의 → 마이페이지에서 이수증), "받은 링크 붙여넣기" 칸(링크나 링크 끝 코드를 넣으면 swim.html?g=…로 이동, 화면 안에서만 처리), 기존 "학교 이름으로 찾기" 목록 유지, "이미 등록하셨나요? 마이페이지에서 이수증 보기"와 문의 전화.
- g가 있을 때 흐름·Firestore 규칙은 그대로. 수업 코드는 별도 짧은 코드가 없어 수업 ID(링크 끝 g 값)를 그대로 받으며, 규칙 변경 없음(swimGroups는 원래 누구나 읽기).
